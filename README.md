## Sobre Nosotros

**SoftSisPro SAS** es una empresa de desarrollo de software especializada en soluciones tecnológicas para pequeñas y medianas empresas colombianas. Desarrollamos sistemas ERP personalizados, plataformas SaaS y aplicaciones web bajo nuestra licencia propietaria **SYNEL**.

Nuestro stack principal incluye **PHP 8+**, **Laravel 11/12**, **Filament PHP 3**, **MySQL** y arquitecturas orientadas a **DDD Lite** con Actions, Services y DTOs.

Además ofrecemos:

- **Consultoría TI** — análisis, diseño y acompañamiento tecnológico para empresas.
- **Automatización de procesos** — diseño e implementación de flujos con **n8n** (self-hosted).
- **Implementación de herramientas open source** — despliegue y configuración de soluciones como ProjectSend, YOURLS, n8n, entre otras.
